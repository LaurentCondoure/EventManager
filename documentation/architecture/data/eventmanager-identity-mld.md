## Tables

### AspNetUsers *(extended)*

Standard ASP.NET Core Identity table, extended with project-specific columns.

```sql
-- Standard Identity columns (managed by framework, not exhaustive)
-- Extended with the following project-specific columns:

ALTER TABLE AspNetUsers ADD
    FirstName           NVARCHAR(100)   NOT NULL DEFAULT '',
    LastName            NVARCHAR(100)   NOT NULL DEFAULT '',
    IsActive            BIT             NOT NULL DEFAULT 1,
    MustResetPassword   BIT             NOT NULL DEFAULT 1,
    CreatedAt           DATETIME2       NOT NULL DEFAULT GETUTCDATE();
```

**Full column reference (project-relevant columns):**

| Column | Type | Constraints | Description |
|---|---|---|---|
| Id | NVARCHAR(450) | PK | Identity default — GUID as string |
| UserName | NVARCHAR(256) | UNIQUE | Set equal to Email |
| NormalizedUserName | NVARCHAR(256) | UNIQUE INDEX | Uppercase — used for lookups |
| Email | NVARCHAR(256) | NOT NULL | User email address |
| NormalizedEmail | NVARCHAR(256) | INDEX | Uppercase — used for lookups |
| PasswordHash | NVARCHAR(MAX) | NULL | Bcrypt hash managed by Identity |
| SecurityStamp | NVARCHAR(MAX) | NULL | Rotated on security-sensitive changes |
| ConcurrencyStamp | NVARCHAR(MAX) | NULL | Optimistic concurrency token |
| FirstName | NVARCHAR(100) | NOT NULL | Project extension |
| LastName | NVARCHAR(100) | NOT NULL | Project extension |
| IsActive | BIT | NOT NULL DEFAULT 1 | Project extension — account active flag |
| MustResetPassword | BIT | NOT NULL DEFAULT 1 | Project extension — force reset flag |
| CreatedAt | DATETIME2 | NOT NULL | Project extension — UTC creation timestamp |

### AspNetUserRoles

Standard ASP.NET Core Identity join table. One row per user-role assignment.

| Column | Type | Constraints |
|---|---|---|
| UserId | NVARCHAR(450) | PK, FK → AspNetUsers.Id |
| RoleId | NVARCHAR(450) | PK, FK → AspNetRoles.Id |

> **Application constraint:** Each user has exactly one role in V1. Enforced in application logic — not a database constraint.

### RefreshTokens

Project-specific table. Stores refresh tokens issued to users.

```sql
CREATE TABLE RefreshTokens (
    Id          UNIQUEIDENTIFIER    NOT NULL DEFAULT NEWID(),
    UserId      NVARCHAR(450)       NOT NULL,
    Token       NVARCHAR(MAX)       NOT NULL,
    ExpiresAt   DATETIME2           NOT NULL,
    IsRevoked   BIT                 NOT NULL DEFAULT 0,
    CreatedAt   DATETIME2           NOT NULL DEFAULT GETUTCDATE(),

    CONSTRAINT PK_RefreshTokens PRIMARY KEY (Id),
    CONSTRAINT FK_RefreshTokens_AspNetUsers
        FOREIGN KEY (UserId) REFERENCES AspNetUsers(Id)
        ON DELETE CASCADE
);

CREATE INDEX IX_RefreshTokens_UserId ON RefreshTokens (UserId);
```

**Token lifecycle:**
- Issued on login and on every successful token renewal
- Previous token is marked `IsRevoked = true` on rotation
- If a revoked token is presented: all tokens for the user are revoked (reuse detection)
- On logout or deactivation: all tokens for the user are revoked immediately

### PasswordHistories

Project-specific table. Tracks the last 5 password hashes per user.

```sql
CREATE TABLE PasswordHistories (
    Id              UNIQUEIDENTIFIER    NOT NULL DEFAULT NEWID(),
    UserId          NVARCHAR(450)       NOT NULL,
    PasswordHash    NVARCHAR(MAX)       NOT NULL,
    CreatedAt       DATETIME2           NOT NULL DEFAULT GETUTCDATE(),

    CONSTRAINT PK_PasswordHistories PRIMARY KEY (Id),
    CONSTRAINT FK_PasswordHistories_AspNetUsers
        FOREIGN KEY (UserId) REFERENCES AspNetUsers(Id)
        ON DELETE CASCADE
);

CREATE INDEX IX_PasswordHistories_UserId ON PasswordHistories (UserId);
```

**History policy:**
- A new entry is inserted each time a password is successfully changed
- Before accepting a new password, the last 5 hashes are checked
- If the history count exceeds 5, the oldest entry is deleted

## EF Core Mapping

### AppIdentityDbContext

```csharp
public class AppIdentityDbContext : IdentityDbContext<ApplicationUser>
{
    public DbSet<RefreshToken> RefreshTokens { get; set; }
    public DbSet<PasswordHistory> PasswordHistories { get; set; }

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        base.OnModelCreating(modelBuilder); // Applies standard Identity schema

        modelBuilder.Entity<RefreshToken>(entity =>
        {
            entity.HasKey(r => r.Id);
            entity.Property(r => r.Id).ValueGeneratedNever();
            entity.Property(r => r.Token).IsRequired();
            entity.Property(r => r.ExpiresAt).IsRequired();
            entity.Property(r => r.IsRevoked).IsRequired().HasDefaultValue(false);
            entity.Property(r => r.CreatedAt).IsRequired()
                  .HasDefaultValueSql("GETUTCDATE()");
            entity.HasOne<ApplicationUser>()
                  .WithMany(u => u.RefreshTokens)
                  .HasForeignKey(r => r.UserId)
                  .OnDelete(DeleteBehavior.Cascade);
            entity.HasIndex(r => r.UserId)
                  .HasDatabaseName("IX_RefreshTokens_UserId");
        });

        modelBuilder.Entity<PasswordHistory>(entity =>
        {
            entity.HasKey(p => p.Id);
            entity.Property(p => p.Id).ValueGeneratedNever();
            entity.Property(p => p.PasswordHash).IsRequired();
            entity.Property(p => p.CreatedAt).IsRequired()
                  .HasDefaultValueSql("GETUTCDATE()");
            entity.HasOne<ApplicationUser>()
                  .WithMany(u => u.PasswordHistories)
                  .HasForeignKey(p => p.UserId)
                  .OnDelete(DeleteBehavior.Cascade);
            entity.HasIndex(p => p.UserId)
                  .HasDatabaseName("IX_PasswordHistories_UserId");
        });
    }
}
```
